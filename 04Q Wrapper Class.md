### Wrapper Class Problem Statements:
1. Write a java program that accepts an integer as a string, and converts it into an integer object using wrapper class. Display the original string, the wrapper object and its primitive value
> eg. "123" -> 123 (as integer)

2. Given 2 numbers as a string, convert them into integers using wrapper class and print their sum.

3. Write a program to accept a number as a string and convert them into an integer object and determine whether the number is even or odd. 

4. Write a program that accepts 3 numbers to convert them into integer objects and find largest number 

5. Create a calculator that accepts 2 numbers as a string and an operation. convert this string into a wrapper object and perform the requested operation.
